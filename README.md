**A local-first Android wallpaper manager that brings still images and video live wallpapers together in a single app.**

**WallpaperHub** is an open-source Android application for organizing and applying still-image and video wallpapers. It combines a local media library, playlist-based wallpaper rotation, previews, and per-item framing controls.

## Why it exists

I wanted one app to manage both still images and video live wallpapers, while keeping a large personal collection without an arbitrary app-level item cap. Existing tools did not fit that workflow, so I started building WallpaperHub and have continued improving it through everyday use on my own phone.

## Features

| Feature | What it does |
| --- | --- |
| 🖼️ Still images + video library | Import, browse, search, filter, favorite, and batch-manage local media |
| 🎬 Video live wallpapers | Play video wallpapers with Android `WallpaperService` and AndroidX Media3 |
| 🔁 Wallpaper rotation | Configure playback order, switching intervals, and transition effects |
| ✂️ Framing controls | Adjust framing, panning, and zoom before applying a wallpaper |
| 🧹 Media maintenance | Check exact duplicates, visually similar items, and media quality |
| 🎨 Themes and scenes | Choose from multiple app themes and scene settings |
| 🧪 Build verification | Kotlin unit tests, Android Lint, GitHub Actions Debug builds, and a Benchmark test module |

**Library-size note:** WallpaperHub does not impose a fixed app-level media-count limit. Practical capacity still depends on device memory, storage, and performance. This is not a claim of unlimited capacity or of testing at every library size.

**Feature boundary:** The public source includes inactive legacy experiments such as `WifiSyncService.kt`. That service is not registered in the current `AndroidManifest.xml`, so **PC/Wi-Fi sync is not an available feature of this public version**.

## Tech stack

- Kotlin, Jetpack Compose, Material 3
- Android `WallpaperService`, AndroidX Media3
- Room, DataStore, Storage Access Framework, Coil
- Android SDK: `minSdk 24`, `targetSdk 35`, `compileSdk 36`
- JDK 17, Gradle Wrapper, GitHub Actions

For component responsibilities and playback data flow, see [Architecture](docs/ARCHITECTURE.md).

## Build from source

Install Android Studio, JDK 17, and Android SDK API 36. Open the repository root in Android Studio, allow Gradle to sync, and then run:

**Windows (PowerShell)**

```powershell
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest
```

**macOS / Linux**

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest
```

The Debug APK is typically located at `app/build/outputs/apk/debug/app-debug.apk`. Use a trusted development environment and standard Android permissions; disabling Android security protections is not required.

> **Public source snapshot:** This repository publishes the necessary source, tests, and build files extracted from an independently maintained private development repository, with a new Git history. Original private-development commits, internal diagnostic screenshots, demo videos, and internal planning archives were not imported.

> **Launcher icon:** The public build currently uses a temporary vector launcher icon rather than the original PNG icon from private development. The original asset may be restored after ownership and file-transfer conditions are confirmed.
